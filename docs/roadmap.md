## اصول

- **ساده برای استفاده، قدرتمند در عمق:** هر کار رایج حداکثر ۲ کلیک یا یک میانبر (⌘K).
- **اول فارسی، اول موبایل، اول سرعت:** امتیاز Lighthouse بالای ۹۵ برای سایت عمومی.
- **هر قابلیت = یک ابزار برای عامل‌ها:** هرچه در UI هست، از طریق MCP/API هم ممکن باشد.
- **شفافیت برای مشتری با کنترل کامل:** همه‌چیز پیش‌فرض خصوصی؛ با سوییچ برای مشتری قابل‌مشاهده.
