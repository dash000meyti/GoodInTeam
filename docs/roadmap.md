| ایده                                                                                  | توضیح                                         |
| ------------------------------------------------------------------------------------- | --------------------------------------------- |

| ✅ خاموش/روشن کردن راهنمای سایت از پنل (`profile.siteGuide`)                          | تنظیمات ← پروفایل سایت                        |
| 🗓️ ویرایش شعار برندها از پنل (`settings.brands`)                                      | فعلاً در فایل‌های ترجمه                       |

| 🗓️ صفحه‌های راهنمای هر ماژول پنل و لینک «بیشتر بدانید» در حباب راهنمای پنل            |                                               |
| ✅ ارقام پیکسلی فارسی                                                                 | شماره قاب‌ها در صفحه‌های فارسی، ۴۰۴           |
| ✅ آیکون‌های پیکسلی برای ماژول‌های داک پنل                                            | ۱۷ آیکون؛ داک، نوار تب، Launchpad             |
| ✅ جستجوی فارسی‌فهم سمت سرور (بلاگ و همهٔ جستجوهای پنل)                               | «ي/ی»، «ك/ک»، نیم‌فاصله، ارقام                |
| 🗓️ آزمون کامل حالت forced colors و پیمایش فقط با کیبورد                               | پروژه‌های Firefox/WebKit آماده است            |

## اصول

- **ساده برای استفاده، قدرتمند در عمق:** هر کار رایج حداکثر ۲ کلیک یا یک میانبر (⌘K).
- **اول فارسی، اول موبایل، اول سرعت:** امتیاز Lighthouse بالای ۹۵ برای سایت عمومی.
- **هر قابلیت = یک ابزار برای عامل‌ها:** هرچه در UI هست، از طریق MCP/API هم ممکن باشد.
- **شفافیت برای مشتری با کنترل کامل:** همه‌چیز پیش‌فرض خصوصی؛ با سوییچ برای مشتری قابل‌مشاهده.
